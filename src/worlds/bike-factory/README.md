# Bike Factory

Featured world and the reference implementation for the generator: a bike supply chain
from tier-2 suppliers to three stores, with hidden rules (seasonality, storms, Store B).

```bash
pixi run dev    # server on $PORT (default 8000) + UI on $UI_PORT (default 5173)
pixi run test   # backend tests
```

File roles and contracts: `src/worlds-template/README.md`.
